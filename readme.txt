TechInventory - Sistema de control de activos internos

Instalación local
1. Iniciar Apache y MySQL desde XAMPP.
2. Crear la base de datos techinventory e importar db/techinventory.sql desde phpMyAdmin.
3. Abrir http://localhost/techinventory/.

Acceso inicial
Usuario: admin
Contraseña: admin

El acceso inicial se habilita cuando la base importada solo contiene las cuatro tablas del parcial. Si se agrega una tabla usuario del sistema original, se usará el inicio de sesión existente en esa tabla.
